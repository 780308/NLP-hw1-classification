# RNN-ARCH-002：正式训练前冻结协议

本阶段沿用 `REP-006-FUSION` `[190,7,7]` 与种子 42、123、2026 的既有 1800/200 内部划分。逐划分归一化只拟合原始的 1800 张训练图；无增强，不访问 `data/val`。上一阶段 `RNN-ARCH-001` 仅作历史参照，不重训。

每个模型先以共享的 `Linear(190,C) → LayerNorm(C)` 投影全部 49 个位置，再重复指定数量的 BiRNN2D 块。每块对同一预归一化 `[B,7,7,C]` 张量分别沿宽度和高度运行参数独立的双向、单层、tanh `nn.RNN`；保留所有位置的输出，拼接后用 `Linear(4HIDDEN,C)` 融合并残差相加；随后是 `LayerNorm(C) → Linear(C,2C) → ReLU → Linear(2C,C)` 和第二次残差相加。最后对 7×7 网格全局平均，接 `LayerNorm(C) → Linear(C,2)`。没有卷积、注意力、Dropout、LSTM 或 GRU。

| 架构 | C | 每方向 RNN 隐层 | 块数 |
|---|---:|---:|---:|
| RNN2D-ARCH-S | 192 | 48 | 2 |
| RNN2D-ARCH-M | 256 | 64 | 3 |
| RNN2D-ARCH-L | 320 | 80 | 3 |

九次正式运行共用 CrossEntropyLoss、AdamW、学习率 `3e-4`、权重衰减 `1e-4`、批量 32、最多 40 轮、验证损失早停耐心 8、反传后梯度裁剪 `max_norm=1.0`。检查点按最高内部验证准确率、同分时较低验证损失选取。三规模全部完成后再按平均准确率及预设的最差种子与参数量规则选型。

正式训练前烟雾检查已核对两轴坐标、独立 RNN 参数、输出形状、损失、反传、裁剪与优化器更新。独立 64 张训练图诊断中，S 在第 5 轮达到 98.44% 拟合准确率；该诊断不计入正式结果。
