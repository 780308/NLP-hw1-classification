# RNN-ARCH-003：最终受控宽度比较的训练前协议

固定 `REP-006-FUSION` `[190,7,7]`、种子 42/123/2026 的原 1800/200 内部划分，以及 `RNN-TRAIN-T1-FLIP` 训练配方。每份训练集由 1800 原图和 1800 张 RGB 水平镜像后重提的特征组成；只从这 3600 张训练图拟合 190 通道归一化。验证始终是 200 张原图。本阶段不访问 `data/val`。

BASE 直接导入已完成的 T1 三种子结果，不重训。仅新运行 WIDE 与 XWIDE 各三个种子，共六次正式运行。三个模型均为逐位置 Linear 投影、三个参数独立的双轴双向 tanh `nn.RNN` 残差块、相同 2 倍通道 MLP、49 位置全局平均分类；只改变 C 和 H，且 H=C/4。

| 架构 | C | H | 块数 |
|---|---:|---:|---:|
| BASE（既有 RNN2D-ARCH-L） | 320 | 80 | 3 |
| RNN2D-ARCH-WIDE | 384 | 96 | 3 |
| RNN2D-ARCH-XWIDE | 448 | 112 | 3 |

训练固定 CrossEntropyLoss、AdamW、学习率 `3e-4`、权重衰减 `1e-4`、批量 32、最多 40 轮、验证损失早停耐心 8、梯度裁剪 1.0；检查点取最高内部验证准确率，同分时取较低损失。无 Dropout、调度器或额外增强。

宽模型的实质改进门槛为：相对 BASE 均值至少 +0.75 个百分点且最差种子下降不超过 0.5 个百分点；或均值至少 +0.50 且最差种子至少 +1.0 个百分点。若样本标准差增加超过 1.5 个百分点，须额外满足均值至少 +1.5 且最差种子不低于 BASE。合格模型中先比较均值；差距不足 0.50 个百分点时依次比较最差种子、标准差、参数量。没有合格模型则保留 BASE。阶段结束后关闭架构优化，只建议独立的训练设置优化，不创建更宽或更深模型。
