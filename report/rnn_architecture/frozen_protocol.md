# RNN-ARCH-001：训练前冻结协议

本实验只使用 `REP-006-FUSION` `[190,7,7]` 和 Stage I 已有的种子 42、123、2026 三份 1800/200 内部划分。每份 190 通道归一化只从对应的 1800 张训练图拟合；无增强，不访问 `data/val`。

| 架构 | 序列 | `nn.RNN` | 分类头 |
|---|---|---|---|
| A | 从上到下 7 行，`[B,7,1330]` | 单向、tanh、隐层 128、单层 | 末隐藏态 → Linear(128,2) |
| B | 同 A | 双向、tanh、每方向隐层 96、单层 | 拼接最终双向隐藏态 → Linear(192,2) |
| C | 行优先 49 单元，`[B,49,190]` | 双向、tanh、每方向隐层 128、单层 | 拼接最终双向隐藏态 → Linear(256,2) |

共同设置：`batch_first=True`、recurrent dropout 0、CrossEntropyLoss、AdamW、学习率 `3e-4`、权重衰减 `1e-4`、批量 32、最多 30 轮、验证损失早停耐心 6。每次反向传播后、优化器更新前使用 `clip_grad_norm_(max_norm=1.0)`。检查点按最高内部验证准确率选，同分时用较低验证损失。

正式实验固定 3 架构 × 3 种子，共 9 次。完成全部运行后，按平均验证准确率的预设 0.75 个百分点差距、最差种子 1.0 个百分点差距、参数量及类别下界 2.0 个百分点例外依次选型。A 与 B 比较方向性，B 与 C 比较序列粒度。

训练前烟雾检查通过；独立 64 张训练图诊断中，A 第 4 轮达到 95.31% 拟合准确率。该诊断不计入九次正式结果，原始记录见 `tiny_overfit_diagnostic.json`。
